## 🧪 Tasks Completed

This internship was structured around four hands-on technical tasks. Each task has its own repository/folder with a full README, screenshots, and a technical report.

### 🔍 Task 1 — Reconnaissance & Vulnerability Scanning
Active reconnaissance and vulnerability scanning on a safe local network using **BlackArch Linux**.
- **Tools:** Nmap, arp-scan, Nikto
- Performed host discovery, port/service enumeration, OS fingerprinting, and vulnerability analysis.
- Identified an exposed DNS service (`dnsmasq 2.51`) and documented findings with severity ratings and remediation recommendations.
- 📄 [`Alfido-Tech-Internship-Task1`](./Alfido-Tech-Internship-Task1-main.zip)

### 🌐 Task 2 — Web Application Security Basics
Web application security testing on **DVWA** (Damn Vulnerable Web Application) hosted on an Apache + MariaDB + PHP stack.
- **Tools:** DVWA, Burp Suite, BlackArch Linux
- Performed Reflected XSS, Stored XSS, and SQL Injection testing; intercepted HTTP requests using Burp Suite.
- Documented mitigation techniques (input validation, output encoding, prepared statements).
- 📄 [`Web-Application-Security-Basics-AlfidoTech-Task2`](./Web-Application-Security-Basics-AlfidoTech-Task2-main.zip)

### 📡 Task 3 — Wireshark Packet Analysis
Network traffic capture and protocol analysis using **Wireshark**.
- **Tools:** Wireshark, Nmap, curl
- Analyzed HTTP, DNS, and TCP (3-way handshake) traffic; identified retransmissions, reset packets, and malformed traffic.
- 📄 [`Wireshark-Packet-Analysis-AlfidoTech-Task-03`](./Wireshark-Packet-Analysis-AlfidoTech-Task-03-main.zip)

### 🚨 Task 4 — Incident Response Simulation
A simulated real-world SOC incident response scenario using terminal-based investigation tools.
- **Tools:** grep, netstat, iptables, base64, pandoc
- Investigated a Windows security log for brute-force login attempts, encoded PowerShell execution, malware deployment, and reverse-shell activity.
- Extracted Indicators of Compromise (IOCs), performed containment actions, and produced a formal incident response report (Severity: **HIGH**, Status: **Contained**).
- 📄 [`Incident-Response-Simulation-AlfidoTech-Task-04`](./Incident-Response-Simulation-AlfidoTech-Task-04-main.zip)
